2. 谷歌 DeepMind 发布 Genie 4：能实时“演”出一个会动、会出声的世界

谷歌DeepMind 10月27日发布了新一代“世界模型”Genie 4，并以研究预览版的形式开放给受信任的测试者。所谓“世界模型”，就是AI不只生成一张图或一段话，而是实时模拟出一个会动、会变化的世界：你推一下这个世界里的东西，它会接着演下去——人怎么走、怎么说话、背景音乐和环境音怎么响，都由模型当场生成。DeepMind说，Genie 4是“原生多模态”的：音乐、环境噪音和互动对话与模拟画面同时生成，而不是事后配音；它的底座来自Gemini家族。DeepMind把这项技术定位为通往通用人工智能（AGI）的一步。

1. 依恋风格决定你怎么爱：《Attached》拆解焦虑、回避与安全三种模式

一篇10月12日的读书笔记重温了心理学家阿米尔·莱文与蕾切尔·海勒的《Attached》（《依恋》）：依恋理论最早用来描述孩子与照顾者的关系，这本书把它搬到了成年人的恋爱里。核心观点有六条：大多数人属于三种依恋风格之一——焦虑型、回避型、安全型，约一半成年人属于安全型；焦虑型伴侣感到距离时会“抗议”，回避型伴侣在亲密加深时会“关闭”；焦虑与回避配对最容易陷入“追—逃循环”；书中最核心的观点是“依赖悖论”：能依靠伴侣的人，反而更自由地去探索世界。

2. 新研究：对关系未来有信心的人，浪漫安全感更强

一篇10月9日的科学报道介绍了一项发表于《BMC Psychology》的研究：研究者发现，“这段关系有未来”这种感觉，可能是浪漫安全感的重要组成部分——不只取决于两个人现在相处得好不好，还取决于当事人对关系能否持续下去有没有信心。研究还指出，对性少数群体而言，这种稳定感还与关系是否得到家人、社群与更广泛社会的接纳和支持有关；研究者杨帆表示，这一发现对关系咨询与心理健康服务有实际意义。
