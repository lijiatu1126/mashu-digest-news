1. HBR：想更高效？试试做减法

哈佛商业评论官方账号近日分享文章《Want to Be More Productive? Try Doing Less》：想改善生活的某个方面，想想“减法”而不是“加法”，每个本能以及每个好心的利益相关者都推着我们做加法——多一个项目、多一个计划、多一个要求，但减法问的是更难的问题：我们愿意放弃什么，才能把重要的事做好？作者认为最有勇气的战略动作往往是一次“删除”——对好的事情说“不”，才能保护真正伟大的事，评论区有人引用Oliver Burkeman的建议：列出25个优先事项，只做前5个，第6项就是你实现前5项的最大干扰。

2. 新研究：在家工作效率更高，关键不是“更努力”而是“精力更稳”

爱荷华大学Tippie商学院的一项新研究（发表于《Organization Science》2026，9月2日经phys.org报道）跟踪了219名混合办公员工整整一周：居家办公的日子里，每个人都比在办公室的日子目标进展更大、干活更快，而且居家越频繁、效率提升越明显。研究者让员工每小时记录精力水平，发现居家日的精力波动小得多——因为干扰少、能自主安排节奏，数据很惊人：在家办公日精力波动降低约33%，精力波动每降低1个百分点，目标进展提高26%。

1. 依恋不是“童年定终身”：21 项研究证实，亲密关系模式一生都在重塑

《Frontiers in Psychology》9月17日发表的编辑部文章，总结了一个大型研究专题（21篇论文）：依恋理论从婴儿研究起步——Ainsworth的“陌生情境实验”发现，婴儿与照顾者之间安全或不安全的联结模式，决定了孩子如何期待亲近和安慰，但几十年证据表明，同样的模式也组织着成年人的亲密关系。关键结论是依恋与其说是“婴儿期一次定型的特质”，不如说是一个“持续发展的过程”——人生每个阶段身边的人（伴侣、朋友、导师）都在重塑它，研究覆盖了从产前联结、青春期、成年伴侣关系到丧亲之痛的完整生命历程。
