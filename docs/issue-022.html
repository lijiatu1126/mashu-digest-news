八、GitHub 新技术 💻

1. morluto/rea —— 让 AI 智能体“看穿”任何软件，单日新增 1.7 万 star 登顶热榜

REA（Reverse Engineer Anything，意为“逆向任何东西”）是一个开源工具包，把 AI 编程智能体（Claude Code、Codex、Cursor、Gemini CLI 等）接到专业的逆向分析工具（Ghidra、IDA、Hopper）上：你用大白话问一句“这个 App 的搜索功能是怎么实现的？”，智能体就会拆开软件——不管是电脑程序、手机 App 还是网站——找出背后的逻辑，带着证据一步步解释给你听，甚至能照着给你重做一个类似功能。它是 10 月 17 日 GitHub 热榜增长第一名，单日新增约 1.7 万 star，总 star 已突破 30 万（仓库页面实时显示 307,435），是本月现象级项目；分析全在本地运行，MIT 协议开源。

🔗 来源

  • GitHub 仓库——github.com/morluto/rea

2. chenglou/handwired —— 把普通 JS 代码“手搓”成神经网络：不用训练，结果分毫不差

chenglou/handwired 是一个脑洞大开的开源项目：把你写的普通 JavaScript 代码（if-else、循环这些）原样“翻译”成一个神经网络，通常神经网络要靠大量数据“训练”才能学会干活，而 Handwired 完全不用训练——它用巧妙的数学变换，让代码逻辑和神经网络的计算结果分毫不差，而且转完之后整个程序还可以继续求导、继续训练。仓库 2026-10-15 才创建，两天就涨到约 1,670 个 star，冲上 GitHub 热榜（TypeScript 区前列）；作者还做了在线演示：一个用 JS 写的小桌面系统，被整个转成神经网络后直接在浏览器里跑起来，不用显卡。
